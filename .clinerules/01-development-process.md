# 开发过程规则

- 严格按照规划文档中的阶段执行。
- 未经用户确认，不得跨阶段实现。
- 第一阶段不开发 WebUI、数据库、MCP 或正式状态提交系统。
- 开始编码前先完成架构和数据契约文档。
- 不得把 API Key 写入源码、配置示例、日志或测试快照。
- API Key 只能通过环境变量读取。
- 新增依赖前必须说明用途。
- 修改架构前先更新 architecture.md。
- 每完成一个小阶段必须运行测试。
- 不得把子模型的假设写入 canon。
- 不得自动修改用户的规划文档。
- 不得删除现有文件，除非用户明确批准。
- 不得执行发布、部署或远程服务器操作。
- 发现需求冲突时先提出问题，不得自行猜测重大产品决策。
